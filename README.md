# Доска расписания

Прототип веб-приложения для школы родителей: сбор расписания и информирование учителей и учеников.

## Возможности
- **Доска** — расстановка уроков по помещениям и учителям (перетаскивание или клик), подсветка ячеек по условиям: можно / с предупреждением / запрещено; строгий режим; авторасстановка; список нарушений за неделю.
- **Условия** — для учителей, групп и помещений: время недоступности, только определённые помещения, лимит уроков в день, «не параллельно с группой». Строгость: запрет или пожелание.
- **Расписания** — личный недельный вид для учителя, группы, помещения; копирование текстом.
- **Настройки расписания** — предметы, учителя, группы, помещения, учебная нагрузка; порядок строк перетаскиванием; фильтры нагрузки.
- **Звонки** — начало уроков, длительность, перемены (каждую можно изменить отдельно), обед, вторая смена.
- **Английский язык** и **Доп. занятия** — отдельные расписания по учебным годам: свои дни недели, строки времени (любые, могут пересекаться и повторяться), преподаватели, группы/кружки, организации с логотипами; проверка накладок по преподавателю и помещению; новый учебный год с переносом настроек.
- **Печать и PDF** — для всех трёх расписаний: вся школа, по группам, по учителям, по кружкам и организациям; A4 книжная/альбомная, цвет или ч/б, логотипы в шапке, подпись внизу; размер текста подбирается под число строк. PDF создаётся библиотекой pdfmake (грузится с cdnjs при первом использовании).
- **Версии** — сохранение версий, возврат к редактированию, создание нового расписания; сохранение в файл `.json` и открытие из файла.

## Как запустить
Откройте `index.html` в браузере. Сборка и сервер не нужны.

Данные хранятся в localStorage браузера; для переноса используйте «В файл» / «Открыть файл…».

## Структура
- `index.html` — исходник приложения (одна страница, без зависимостей, кроме шрифтов Google Fonts).
- `dist/school-schedule-test/` — пакет для тестировщиков: `raspisanie.html` + `README.txt` со сценариями проверки.
- `dist/school-schedule-test-v0.6.zip` — тот же пакет архивом.
